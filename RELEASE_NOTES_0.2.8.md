# CutData AI 0.2.8

- Tool names no longer carry "needs review". The Guided tool list shows the plain name, and names saved by earlier releases with "— needs review" on the end are tidied on first start. The review status itself is kept.
- A **Needs review** tick box sits under the tool selector for a library tool. Ticking or unticking it saves straight to the Tool Library record and keeps the material, coating and thread values already set for the job.
- The tool summary line only mentions review when the linked insert still needs it. The Tool Library window keeps its status column and the tick box in Edit.
